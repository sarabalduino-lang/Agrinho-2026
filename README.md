# “Frutas que viram tinta e depois arte”

Projeto desenvolvido para o concurso Agrinho.

A proposta é demonstrar que frutas ricas em pigmentos naturais podem ser utilizadas para produzir tintas ecológicas, que depois são aplicadas na criação artística.
# 🎯 Objetivo do Projeto
O objetivo do projeto “Frutas que viram tinta e depois arte” é demonstrar, de forma interativa e educativa, como recursos naturais podem ser transformados em alternativas sustentáveis aos produtos industriais.

O site busca conscientizar sobre a importância da reutilização de alimentos e do uso de pigmentos naturais, incentivando práticas ecológicas e criativas.

Além disso, o projeto une tecnologia, sustentabilidade e arte, mostrando que é possível utilizar a programação para transmitir conhecimento ambiental de maneira dinâmica e visual.
